`testrail-ai-mcp --env-file <absolute path>` loads TestRail settings from a file that several MCP clients can share. Variables already in the environment take precedence. The setup message points to the client's `env` block and the new flag, and the README shows configuration for Claude Code, Codex, VS Code, Cursor, Claude Desktop and Windsurf.
